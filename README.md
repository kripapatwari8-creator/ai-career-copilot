AI Career Copilot

AI-powered Resume Analyzer + ATS Checker + FAANG Career Mentor.

# Features:
- Resume ATS Score Analysis
- AI Career Guidance
- Resume Skill Detection
- FAANG Readiness Score
- Personalized Learning Roadmap
- PDF Resume Upload
- Resume Improvement Suggestions

# Tech Stack:
# Frontend
- React.js
- Tailwind CSS
# Backend
- FastAPI
- Groq API (Llama 3)
- PyMuPDF

# Deployment
- Vercel (Frontend)
- Render (Backend)
